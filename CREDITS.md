# Project Credits & Data Sources

This project utilizes public transportation data and mapping services to provide nearby bus station route in Davao City.
DB nearMe - Davao Bus nearMe
## Bus Route Data
The route coordinates, station locations, and schedules for the following routes were provided by the **Davao Bus Community**:

* **R102**: Toril to GE Torres
* **R103**: Toril to Roxas
* **R402**: Mintal to GE Torres
* **R403**: Mintal to Roxas
* **R503**: Bangkal to Roxas
* **R603**: Buhangin to Roxas
* **R763**: Panacan via Buhangin to Roxas
* **R783**: Panacan via Angliongto to Roxas

Special thanks to the contributors who collected the high-precision GPS coordinates for these stations.

##Mapping & Routing Services
* **Routes**: [Github](https://github.com/ttg-eng/routes) (Huge thanks to Sir Jay Em for a open source json lat, and long).
* **Map Engine**: [Leaflet.js](https://leafletjs.com/) (Open-source JavaScript library for interactive maps).
* **Map Tiles**: [OpenStreetMap](https://www.openstreetmap.org/) contributors (© OpenStreetMap).
* **Road Routing**: [OSRM (Open Source Routing Machine)](http://project-osrm.org/) for providing the street-snapped path geometries.
